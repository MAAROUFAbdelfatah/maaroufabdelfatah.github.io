About

Backend engineer with a full-stack and research edge

I am a backend engineer working primarily with Java and Spring Boot, building and maintaining the services that applications depend on — REST APIs, database integration, and application logic backed by solid testing.

My full-stack experience spans Angular and Thymeleaf frontends, and I work within Agile and DevOps delivery flows (Scrum, Jira, Jenkins, GitLab). I have strong foundations in algorithms, data structures, Object-Oriented Programming (OOP), and Aspect-Oriented Programming (AOP).
